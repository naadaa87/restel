# 레스텔 운영 매뉴얼 (비개발자용)

## 1. 매일 하는 일
1. `/admin` 접속 → 대시보드에서 **새 예약 요청**, **승인 대기 호스트**, **검토 요청 공간**, **새 문의** 숫자를 확인합니다.
2. 새 예약 요청 → 열어서 날짜·시간·인원을 확인 → 가능하면 상태를 **확정**으로 바꾸고 "고객에게 함께 보낼 안내"에 결제 방법과 입장 안내를 적습니다. (이메일 키가 설정되어 있으면 고객 이메일로 자동 발송, 카카오톡은 연락처로 직접)
3. 불가하면 **불가**로 바꾸고 대체 시간을 메시지로 제안합니다.
4. 이용이 끝난 요청은 **완료**로 바꿉니다.

## 2. 호스트(파트너) 입점 처리
1. 호스트가 `/host/register`에서 4단계 가입(계정 → 사업·공간 정보 → 운영 기준 서약 → 가입)을 마치면 대시보드 "승인 대기 호스트"에 표시됩니다.
2. `/admin/hosts` → 호스트를 열어 사업 형태·사업자번호·공간 형태·서약 동의 시각·결제/정산 계좌를 확인하고 **승인**합니다. 보완이 필요하면 상태는 "승인 대기"로 두고 메모를 적어 저장(호스트 화면과 메일로 전달).
3. 호스트가 공간을 등록하고 **검토 요청**을 누르면 `/admin/spaces`에 "검토 요청"으로 올라옵니다. 호스트는 필수 항목(한국어·영어 이름, 소개, 주소, 세션 1개, 사진 3장, 기준 점검 필수 항목)을 다 채워야 검토 요청을 누를 수 있습니다.
4. 공간을 열어 **호스트 자가 점검 결과**와 사진·문구·세션 가격을 확인합니다. 검토자 확인: 사진에 침대·호텔식 침구·샤워 부스가 없는지, 운영 종료가 자정 이전인지, 가격이 권장 범위인지, 영어 소개가 있는지.
5. 통과하면 상태를 **공개 중**으로 → 지점 목록(`/spaces`)과 사이트맵에 바로 노출됩니다. 보완이 필요하면 **보완 요청** + 메모.
6. 공개 중인 공간을 호스트가 수정하면 자동으로 다시 "검토 요청" 상태가 됩니다(휴무일·입장 안내만 바꿔도 동일).

## 3. 호스트가 하는 일 (`/host`)
- **대시보드**: 시작하기 진행도(8단계), 할 일(응답 필요·답장 필요·결제 미완료·입장 안내 전·지난 세션 처리·리마인더), 오늘 세션, 공지.
- **예약**: 요청을 열면 단계별로 처리합니다. ① 확정(금액·결제 방법, 고객 언어 안내문 자동) 또는 불가 → ② 결제 안내 보내기 → 입금 확인(현장 결제는 완료 때 금액 입력) → ③ 입장 안내 보내기(공간 설정의 입장 안내문이 자동으로 들어감) → ④ 이용 완료 / 노쇼. 취소·환불, 내부 메모, 7개 언어 템플릿, 진행 기록이 함께 있습니다. 달력에서 월별 세션과 휴무일을 봅니다.
- **내 공간**: 기본 정보 / 소개(7개 언어) / 세션·요금 / 운영·안내(휴무 요일·휴무일·정리 시간·입장 안내문) / 레스텔 기준 점검 / 사진.
- **정산**: 월별 완료 매출·수수료·정산액, 세션별 내역, 정산서 상태.
- **호스트 센터**: 운영 가이드, 공지, 1:1 문의(답변은 같은 화면과 메일로), 자료실(로고·인쇄용 안내문·점검표).
- **설정**: 프로필·사업 정보, 결제·정산(고객 결제 방법, 입금 계좌, 입금 기한, 환불 규정, 정산 계좌, 세금 처리), 서약 내용, 비밀번호.

## 3-1. 월별 정산 (관리자)
1. 매월 초 `/admin/settlements` → "발행 대기"에 지난달까지 완료 매출이 있는 호스트가 나옵니다. 수수료율(기본 15%)을 확인하고 **정산서 발행**(호스트에게 메일).
2. 호스트는 `/host/settlement`에서 정산서와 세션별 내역을 봅니다. 이견은 호스트 문의로 들어옵니다.
3. 송금(또는 수수료 수령)이 끝나면 **지급 완료**로 표시합니다. 정산 계좌가 없는 호스트는 "계좌 미등록"으로 표시되니 먼저 등록을 요청하세요.
4. 호스트가 직접 받은 결제(계좌이체·현장)는 호스트가 수수료를 레스텔에 송금하고, 레스텔이 받은 결제(온라인 카드, 준비 중)는 레스텔이 수수료를 제한 금액을 지급합니다.

## 3-2. 호스트 공지·문의
- `/admin/notices`에서 공지를 쓰면 호스트 대시보드와 호스트 센터에 표시됩니다(상단 고정 가능).
- 호스트 1:1 문의는 `/admin/inquiries`의 "호스트 1:1 문의" 탭에 모입니다. 답변을 저장하면 호스트 센터 문의 내역에 그대로 보이고, 체크하면 메일로도 갑니다.

## 4. 고객이 보는 것
- 홈 → 세션·요금 → 지점 → **예약 요청** 폼(날짜·시간·인원·연락처·동의) → 요청번호 발급 → `/my`에서 요청번호+연락처로 상태·메시지 확인, 취소.
- 모든 화면 상단에 "숙박시설이 아닌 휴식 공간대여" 고지가 고정되어 있습니다.

## 5. 문구·가격 바꾸기 (GitHub)
- 직영 신촌 가격·운영시간·소개: `src/data/flagship.ts`
- 세션 설명·규칙·FAQ·약관 등 문구: `src/i18n/locales/ko.json` (다른 언어도 같은 키로)
- 연락처·사업자 정보: `src/config/site.ts`
- 저장(Commit) 후 1~3분 뒤 반영. 반영 안 되면 Cloudflare → Workers & Pages → restel → Deployments 에서 빌드 로그 확인.

## 6. 문제가 생겼을 때
| 증상 | 확인 |
|---|---|
| 관리자 로그인 안 됨 | Variables and Secrets 에 ADMIN_EMAIL / ADMIN_PASSWORD 가 Secret 타입으로 있는지 |
| 호스트가 "검토 요청"을 못 누름 | 공간 편집 상단의 "검토 요청 전에 채울 항목"을 호스트에게 안내 (사진 3장, 영어 이름, 기준 점검 필수 항목 등) |
| 호스트가 확정할 때 "계좌 미등록" 오류 | 호스트 설정 > 결제·정산에 입금 계좌 등록 필요 |
| 정산 대기 목록에 호스트가 안 보임 | 세션이 "이용 완료"이고 결제 금액이 입력됐는지, 이번 달이 아닌 지난달 세션인지 확인 |
| "데이터베이스가 연결되지 않았습니다" | Deployments 로그에 D1 프로비저닝 오류가 있는지. wrangler.jsonc 의 d1_databases 유지 |
| 호스트 사진 업로드 실패 | R2 바인딩(MEDIA) 확인. 임시로 "URL 추가" 사용 |
| 알림 메일이 안 옴 | RESEND_API_KEY / MAIL_FROM 설정, Resend 도메인 인증 |
| 번역이 영어로 보임 | 해당 언어 JSON에 키가 없으면 영어→한국어로 자동 대체. 해당 키를 추가 |
